## 1. 체감 응답 시간 — SSE 스트리밍

| 지표 | 평균 | 범위 |
|---|---|---|
| 첫 토큰 도착 (TTFT, 질문 임베딩·벡터 검색 포함) | **1.59초** | 0.85 ~ 2.07초 |
| 답변 완료 (스트리밍이 없다면 이때까지 빈 화면) | 2.63초 | 1.67 ~ 3.47초 |
| 대기시간 단축 (1 − 첫 토큰 ÷ 완료) | **39%** (평균 시간 기준) | 질문별 20 ~ 62% |

- 답변이 길수록 효과가 큼: 가장 긴 답변(828자)은 첫 토큰 0.85초 / 완료 2.27초로 **62% 단축**
- 첫 토큰 시간에는 LLM 응답 대기 외에 질문 임베딩(OpenAI API)과 PgVector 검색 시간이 포함됨

## 2. 업로드 응답 — 비동기 인덱싱

| 지표 | 측정값 |
|---|---|
| 업로드 요청 → 202 응답 | **0.17초** |
| 업로드 → 인덱싱 완료(DONE) | 3.2초 (22개 청크) |

- 동기 처리였다면 사용자는 인덱싱이 끝날 때까지(이 문서 기준 3.2초) 응답을 기다려야 함 — 문서가 클수록(청크 수에 비례) 차이가 커짐

## 3. LLM 입력 토큰 — RAG

| 문서 | 문서 전체 | 질문당 LLM에 전달된 문서 토큰 | 절감 |
|---|---|---|---|
| 이 README (22개 청크) | 8,171 토큰 | 평균 1,804 토큰 (1,716 ~ 1,845) | **약 78%** |
| 실사용 PDF 문서 (11개 청크) | 2,677 토큰 | 최대 1,649 토큰 (가장 긴 청크 5개 기준) | 최소 38% |

- 질문마다 상위 5개 청크만 전달하므로, LLM에 들어가는 문서 토큰은 **문서 크기와 무관하게 약 1,700 ~ 2,500 토큰으로 일정** → 문서가 클수록 절감률이 높아짐
- 토큰 수는 GPT-4o 토크나이저(`o200k_base`, jtokkit)로 계산했으며, 시스템 프롬프트·질문·대화 이력 토큰은 제외한 문서 부분만 비교

> 측정 횟수가 질문 5개로 적고 OpenAI 응답 시간은 시점에 따라 달라지므로, 수치는 경향을 보여주는 참고값입니다.
